How the lane moves

Read, decide, mask, prove, forget.

01

Read locally

Text enters the detector in process. No raw document is written to the run store.

02

Find structure

Checksums, patterns, and explicit labels catch high-signal personal data.

03

Mask carefully

Stable tokens preserve joins without exposing names, accounts, or credentials.

04

Receipt the change

Hashes describe source, output, and finding set without repeating the private content.

05

Keep less

The persisted run keeps counts and receipts. The sensitive words leave with the caller.
