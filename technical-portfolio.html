Catalog

Files with a clearer purpose.

This page sits beside the README and names the most important runtime components and the role each one plays.

Video lane

Transcript-led temporal work

The video surface does not claim end-to-end cinematic editing. Instead, it produces evidence windows and cleanup suggestions from transcripts, frame signals, and audio energy traces.

contracts

`contracts.py`

Tensor payloads, retrieval schemas, quality reports, provenance receipts, temporal alignment windows, video packet schemas, and benchmark results all live here.

service

`service.py`

The coordination layer for contract inference, research fallback, retrieval, metrics, quality profiling, provenance, video cleanup, and stream events.

rust core

`crates/multimodal-core`

A compiled lane for deterministic tensor signatures and transcript-led temporal cuts.

retrieval

`retrieval.py`

Memory index by default. Qdrant path when the environment is ready.

video

`video.py`

Transcript grouping, silence gap detection, filler word cuts, retained spans, and evidence packet assembly.

data quality

`quality.py` and `signal_math.py`

Shared tensor summaries, modality health checks, fusion-readiness scoring, and pairwise alignment readings.

drift

`drift.py` and `drift_store.py`

Reviewed population baselines, modality-level drift deltas, alignment drop, and persisted baseline records.

connectors

`connectors.py` and `connector_store.py`

Typed row pulls for local CSV, local Parquet, S3-backed Parquet, local NDJSON, HTTP JSON, HTTP NDJSON, and public HTML pages, plus persisted ingest benchmarks.

recipes

`recipes.py` and `recipe_store.py`

Compiled manifests with dataset-resolution evidence, launch topology, export commands, and persisted handoff records.

pipelines

`pipelines.py` and `pipeline_store.py`

Raw event pairing into aligned inference batches, persisted run records, and dropped-event accountability.

replay

`replay.py`

NDJSON lineage export, deterministic artifact digests, and replay comparison for saved pipeline runs.

provenance

`provenance.py` and `alignment.py`

Deterministic payload receipts and timed observation grouping for cross-modal corroboration.

ontology

`domain_ontology.py`, `liability_surface.py`, and `ontology_store.py`

Enterprise artifact ingestion, compiled governance constraints, live trace comparison, and persisted ontology snapshots.

bias

`bias_taxonomy.py`

A sixty-category register for where bias enters a system, plus a stage-aware assessment lane.

job lane

`job_store.py`

A persisted SQLite-backed lane for longer-running video cleanup and multimodal batch inference work.

registry

`registry.py` and `legacy.py`

The bridge between the new runtime edge and the older research model files already present in the repo.

sdk

`sdk/typescript`

A small client for health checks, quality, provenance, planning, inference requests, alignment windows, and the WebSocket stream.

operations

`Dockerfile`, `compose.yaml`, `monitoring/`, and `sql/runtime_schema.sql`

Local container bring-up, Prometheus scrape configuration, explicit runtime tables, and a concise operations path.

openapi

`scripts/export_openapi.py` and `scripts/generate_sdk_surfaces.py`

The runtime can export its own contract and regenerate Python and TypeScript client surfaces from that document.

readiness

`readiness.py` and `scripts/export_readiness_report.py`

A typed report that keeps route count, test count, connector coverage, recipe evidence, and operating boundaries together in one inspectable surface.
